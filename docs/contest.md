# Contest notes

## Event

- **Name:** WE WEB IN THE WEB WORLD — Website Designing Contest  
- **Audience:** Classes IX–XII · teams of 3  
- **Theme:** Landing page for a modern village social network  

## Hard rules (from the brief)

1. Home page named **Sample** in the URL → we use `sample.html`  
2. Fast in major browsers  
3. No animation **software** (CSS/JS motion is fine)  
4. No others’ templates  
5. Images must load; every image needs **alt** and **title**  
6. No personal website / personal social links  
7. Email link before the printed deadline (verify time on the sheet)  

## Judgement rubrics

1. Relevance and accuracy of content  
2. Spelling and grammar  
3. Visual appeal  
4. HTML standards  
5. Functionality / working links / readability

## 90-second demo script

1. “Chaupal Connect is a digital banyan tree — villagers meet, discuss issues, share news.”  
2. Point to **Village Buzz** ticker.  
3. Open **Feed** — show a filter or Support.  
4. **Voice** — English is the default; tap mic, speak, show transcript. Optionally switch to Hindi.  
5. **Fair calendar** — one upcoming mela.  
6. Palette: terracotta, olive, mustard — warm and inclusive.  

## If asked “where is the full social media app?”

> The brief asked us to design the **landing page** for a modern village social network. This is that entry experience. The Feed and Voice demos show how people would use Chaupal Connect; a full backend was outside the contest scope.
