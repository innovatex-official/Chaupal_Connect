# Overview

## What this project is

**Chaupal Connect** is a **landing page** for a fictional modern village social network — a digital chaupal / banyan-tree gathering place.

It is **not** a full social media backend (no login, database, chat server, or real posts API). The contest brief asks for a **landing page** with specific UI features, not Instagram for villages.

## Contest framing (one sentence)

> Design a landing page for a modern village social network: warm, inclusive, earthy palette, with a gossip/news ticker, community fair calendar, and Voice-to-Text for accessibility.

## What ships

| Community fair calendar | Required |

| Village Feed (client-side preview) | Extra — product feel |
| Join form, FAQ, gallery, testimonials | Extra — completeness |
| GitHub Pages live link | Submission |

## What we deliberately did **not** build

- User accounts / auth  
- Real-time chat or feed database  
- Translation app (Voice is accessibility transcription only)  
- Third-party templates or animation software  

If a judge asks “where is the social network?”, answer:

> This submission is the **entry experience** for Chaupal Connect. The brief asked for a landing page; Village Buzz, the Feed preview, Fair Calendar, and Voice-to-Text show how villagers would discover and use the platform.
